# PaperFly Investor Portfolio

## Goal
Build a complete single-page pitch website that mirrors PaperFly’s warm, eco-industrial presentation style and communicates the venture clearly to COMQUEST judges and investors.

## What I’ll build
- Sticky responsive navigation with smooth section links, pitch-download action, and prominent ₹20L ask.
- High-impact opening section with PaperFly’s positioning, key projections, and direct paths to the product and offer.
- Executive problem summary covering DU election waste, institutional compliance, and the price-quality market gap.
- Product suite with a tactile, notebook-style interactive “The Note” provenance insert and blind-sourcing explanation.
- Three-mode operational workflow covering sorting, chemical-free milling, and compliance certification.
- Investor-ready business model, revenue mix, unit economics, three-year financial comparison, funding allocation, and downside sensitivity.
- ESG impact dashboard, SDG markers, founder profiles, competition attribution, and cited source list.
- A print-optimized pitch PDF generated from the page when “Download Pitch PDF” is selected.

## Visual direction
- Warm unbleached-paper canvas, deep forest ink, terracotta kraft accents, white content surfaces, and restrained warm borders.
- Plus Jakarta Sans for interface and data; Newsreader for editorial details and “The Note.”
- Tactile paper texture, compact investor-grade charts, modest rounded corners, and subtle motion with reduced-motion support.
- Responsive layouts designed for the current mobile preview and expanded desktop presentation.

## Interactions
- Smooth in-page navigation with an accessible mobile menu.
- Operational workflow tab switcher.
- “The Note” blind-sourcing disclosure with Named, Group, and Anonymous examples.
- Financial/revenue visuals, allocation bar, and clear call-to-action focus states.
- Download/print action and buttons that navigate to the relevant sections.

## Technical details
- Implemented as the home page using the existing TanStack structure and semantic Tailwind v4 design tokens.
- Add route-specific metadata for search and social previews.
- Use lightweight inline vector icons and CSS illustration details; no external runtime services or data storage required.
- Validate compilation, desktop/mobile rendering, navigation, tabs, and print/download behavior.
